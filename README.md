# Food Recipe Finder 🍲

A React-based web application to search and explore recipes with beautiful UI. Built with Vite, React, and Bootstrap.

---

## **Live Demo**

[View on Vercel](https://frontend-e71tgd825-nandini-ss-projects.vercel.app)

---

## **Features**

* Search recipes by ingredients or name.
* Display recipe details with images.
* Responsive design using Bootstrap.
* Easy-to-use interface for food enthusiasts.


## **Tech Stack**

* **Frontend:** React, Vite, Bootstrap
* **Deployment:** Vercel
* **Version Control:** Git & GitHub

---

## **Setup Instructions**

1. **Clone the repository**

```bash
git clone https://github.com/Nandinigowda18/Food-recipe-finder.git
cd Food-recipe-finder/frontend
```

2. **Install dependencies**

```bash
npm install
```

3. **Run the project locally**

```bash
npm run dev
```

* Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production**

```bash
npm run build
```

* The production-ready files will be in the `dist` folder.

5. **Deploy to Vercel**

```bash
vercel --prod
```

* Follow the prompts and your app will be live.
